# GoreeCloud Messenger documentation

This directory is the canonical home for Messenger human-readable repository documentation. `README.md` remains the root entry point; source code, Go module metadata, Platform Contract controls, and GitHub-specific security guidance remain in their technically appropriate locations.

## Canonical records

- `SPECIFICATIONS.md` — product and engineering requirements.
- `FEATURES.md` — current capability overview.
- `IMPLEMENTED-FEATURES.md` — implemented capability authority.
- `PLANNED-FEATURES.md` — planned, blocked, and incomplete capability authority.
- `CHANGELOGS.md` — repository-local changelog.
- `BENEFITS.md` — supportable product and platform benefits.
- `COMPETITIVE-OBJECTIVES.md` — differentiation and benchmark objectives.
- `BRANDING.md` — repository-local branding requirements.
- `USER-MANUAL.md` — current user/developer behavior and limitations.
- `NOTES.md` — current development and maintenance notes.
- `PRIVACY.md` — current Development privacy boundary.

## Supporting records

- `architecture.md` — product architecture and trust boundaries.
- `PLATFORM_CONFORMANCE.md` — platform-conformance evidence.
- `data-messaging.md` and `data-http-api.md` — Data messaging and HTTP contracts.
- `durable-receipt-store.md` — Development durability contract.
- `runtime-diagnostics.md` — minimized runtime diagnostic boundary.
- `development/` — bounded Development design and hardening records.

Repository security guidance is maintained at `.github/SECURITY.md`.
